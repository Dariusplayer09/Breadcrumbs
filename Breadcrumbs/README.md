# BreadCrumbs
#### Video Demo:  <https://youtu.be/NsiO6biOokM>
#### Description:
Breadcrumbs is a chrome file extension which keeps track of your thoughts by using JavaScript, HTML, CSS and Manifest of course.
It is designed as a convinient "exercise" specifiaclly for neurodivergent/ADHD people, to help them understand how they got to their
idea/page in one convinient click, removing the hassle to have to go on the history search bar and read everything.
Doing so, the tool reinforces neural pathways involved in working memory, attention control, and metacognition, which can benefit neurodivergent cognitive organization.
